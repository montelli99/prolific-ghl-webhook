## ROLES

| Role | Person | Description |
|---|---|---|
| Student | Mentee | Performs operator work under Montelli/Kayla supervision. Same responsibilities as Operator. |
| Operator | Montelli | Primary contact person. Collects information, evaluates deals, submits handoffs. |
| Kayla | Kayla Mauser | Generates offers, negotiates, closes. Sends offers via AI. Runs the operation. |
| Seth | Seth | Underwrites deals, generates LOIs. Gateway for all formal offers. |
| Jaxon | Jaxon | Generates offers, negotiates, closes. Runs group chats. Handles follow-up calls. |
| Closer | Kayla, Jaxon | Generates offers, negotiates, closes. Takes over from operator on hot leads. |
| Disposition | Kayla, TC | Arranges inspections, appraisals, title, closing. Post-acceptance logistics. |
| Underwriting | Seth | Runs deal numbers. Determines whether a deal passes. Generates LOIs. |
| Negotiation | Kayla, Jaxon | Handles all counters, objections, price discussions. Operator never negotiates. |

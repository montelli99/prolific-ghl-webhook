// "Typically if we go to the bank at 20% down at 8% interest, that's our
//  baseline. We're putting 50% down so it makes sense for both parties.
//  With 10% interest plus 50% down, we're essentially double-financing.
//  We can agree on all terms except the interest rate.
//  What if we agreed on [lower rate] and [reduced/neutral down payment]?"
//
// If seller wants monthly payments instead of balloon:
// "If you want monthly payments, we can't bring 50% down.
//  We can come in at [lower down payment], cover all closing costs,
//  and pay monthly — or we can do 50% down with no monthly payments
//  and pay a lump sum in 72 months. Which structure works for you?"
//
// If seller has other buyers circling (leverage):

//  What would it take to get this done today?"

// Key principle (from 17A-OH transcript): Montelli is RELAY, Kayla NEGOTIATES

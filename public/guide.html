Getting Your GHL API Token

5 minutes. You'll need your GHL login.

1
Go to Integrations
Log into app.gohighlevel.com. Click Settings (gear icon, bottom left sidebar). Click Integrations.
2
API Keys
Scroll to API Keys section. Click Create New Key.
3
Create Private Integration
Name it: AI REI Pipeline
Select scopes:
• opportunities.readonly
• contacts.readonly
• locations.readonly
4
Give Us the Token
Copy the token. Also need your Location ID (under Settings → Business Info).
⚠️ The token is read-only. Atlas can see opportunities, contacts, and locations — but cannot modify anything in GHL. Safe to share.
Once you have the token, paste it at:
http://localhost:3000/dashboard
